# 🌦️ Weather Tracker

A weather tracking website in early development.

## 🧬 Architecture
* **Frontend:** SpringDoc OpenAPI
* **Backend:** Spring Boot 4.1.2
* **Database:** H2 Database

## 🔧 Prerequisites
* `JDK 25+`
* `Maven 3.x`

## 🚀 Getting Started
1. Run `WeatherTrackerApplication.java`
2. Open **http://localhost:8080/swagger-ui/index.html**
